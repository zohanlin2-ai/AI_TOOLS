# AI Tools

This directory organizes small tools and development projects used at work.

## Current contents

- `BSP_Prompt_Harness/`: A BSP / Embedded Linux task prompt generator.
  - `bsp-prompt-harness.html`: A browser-based single-page tool that generates prompts for Docker builds, BSP downloads, patch application, and debug analysis.
- `ai-terminal/`: Planning documentation for the Windows AI Terminal project.
  - `README.md`: Describes the first-release scope, technology choices, and architecture.
- `Schematic_diagram/`: Private workflow for efficient, traceable hardware schematic analysis.
  - `README.md`: Explains the generic Skill + per-PDF private-note workflow.
  - `SKILL.md`: Reusable instructions for creating component-connectivity and controller pin/function maps.
  - Source PDFs and per-document private analysis notes remain local and are excluded from Git.
